## ✨ ¿Qué ofrece RBK?

🔄 **Actualizaciones centralizadas** --- Las nuevas versiones se
publican mediante Releases y se reflejan en el índice.

🌎 **Fuentes multilenguaje** --- Varias extensiones ofrecen fuentes
separadas por idioma.

📦 **Instalación independiente** --- Instala únicamente las extensiones
que quieras utilizar.

🧭 **Integración con Mihon** --- Distribución mediante su sistema de
repositorios de extensiones.

## 🛠️ ¿Algo dejó de funcionar?

Los sitios pueden modificar su estructura sin previo aviso y una
extensión puede requerir una actualización.

**[🐛 Abrir un
Issue](https://github.com/RUBIKOF/Mihon-Extensions-RBK/issues)**

Incluye el nombre de la extensión, una descripción del problema y, si
existe, el mensaje de error.
